# MY LIFE（PWA試作版）

「最初はしっかり設定、あとは簡単に続ける」個人専用の生活設計アプリ。
Androidのホーム画面に追加して使うPWAです。データはすべて端末内（IndexedDB）に保存され、サーバーには送信しません。

## 動かし方（PC）

```
npm start      # http://localhost:8080 で起動（依存パッケージなし）
npm test       # 計画・分析ロジックの自己テスト
```

## Androidで使う

PWAのインストールには HTTPS での配信が必要です。アプリ本体（HTML/JS/CSS）だけを無料の静的ホスティング（GitHub Pages など）に置けば、記録データは各端末の中にだけ保存されます。
Chromeで開き、メニューの「ホーム画面に追加／アプリをインストール」を選ぶと、オフラインでも動作します。

## 構成

| ファイル | 内容 |
|---|---|
| `js/knowledge.js` | 未来予測の根拠データ（A：一般的な知見）・出典・注意点。文章からの読み取り |
| `js/planner.js` | 固定予定を優先した週間プランの自動配置と実現可能性チェック |
| `js/analysis.js` | 達成率、初回値との比較（B）、データ不足（C）、今日のひとこと、週次提案 |
| `js/experts.js` | AI専門家8名の設定（**現在は仮の領域枠。既存設定に差し替え予定**） |
| `js/ai.js` | オンデバイス生成AI（対応端末のみ。なければルールベースで動作） |
| `js/backup.js` | AES-GCM 暗号化バックアップ |
| `js/views/*` | 画面（初回設定5段階・今日・目標/未来予測・週間/振り返り・健診ほか） |

## 予測の方針

- A：科学的知見に基づく一般的な期待効果／B：本人の記録の傾向／C：記録不足で判断できない
- 疲労・血糖・体重・筋肉量・検査値の改善率や将来の数値は表示しない
- 変化の原因は断定しない。健診の要再検査などは医療機関の指示を優先

## 既知の制限

- 健診原本からの自動読み取り（OCR）は未対応。原本を見ながら入力し「照合済み」にする方式
- 通知（リマインダー）は未実装
